# MOTA landing page

A responsive static landing page for the MOTA rider and driver app. It uses the official logo from the mobile repository and illustrative interface previews based on the current app flow. The previews are not screenshots of a released build.

## Run locally

```sh
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Release links

Set the official HTTPS Android APK and iPhone distribution URLs in `config.js`. Until then, both download controls show a pending state and do not navigate to an unverified file. Replace the partnership contact section with an official contact address and confirmed partner names when available.
